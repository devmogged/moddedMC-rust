- Entry point: com.magistuarmory.fabric.EpicKnightsFabric; optional mod-menu entry: com.magistuarmory.fabric.config.ModMenuFabric.
- The original fabric.mod.json requires Minecraft >=26.3 and <26.4; Java >=25; Fabric Loader >=0.19.5; Architectury >=22.0.5; Cloth Config >=26.3.159; Fabric API any version.
- Includes magistuarmory.common.mixins.json. Mixin contents and resulting runtime behavior require independent examination.
- The 453 parsed recipes comprise 366 shaped, 47 smithing transforms, 33 dye, 4 blasting, and one each of magistuarmory:armor_decoration_recipes, magistuarmory:decoration_remove_recipes, and magistuarmory:heraldry_recipes. The 3 bespoke recipe types should be treated as behavior requiring source comparison, not normal vanilla crafting.
- Original 10.18 Fabric bytecode was decompiled for private analysis to D:/mc-ref/epic-knights-10.18/decompiled. Neither jar nor decompiled files belong in Git.
- Engine submodule is not initialized in this mod-only worktree; use shared engine binaries N:/mmc-shared/bin/9d9e63f924-e1b1f49 for scenarios and do not rebuild engine here.
