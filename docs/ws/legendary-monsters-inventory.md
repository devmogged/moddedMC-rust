## Living versus technical entity types

The registry declares **32 `MobCategory.MONSTER`**, **2 `MobCategory.CREATURE`** (`skeloraptor`, `dune_sentinel`), and **58 `MobCategory.MISC`** (projectiles, temporary effects, camera entities and other helpers). `MobCategory` is not itself proof of boss/AI roles.

In the publicly available older Java source, `Cloud_GolemEntity`, `PossessedPaladinEntity` and `TheObliteratorEntity` extend `IAnimatedBoss`, and eleven mob classes extend `IAnimatedMiniBoss`. The latest 2.2.4 decompiled `TheObliteratorEntity` confirms its `LMBossInfoServer` bar with phases, visibility, player tracking and health progress. Inspect each latest class independently before assigning boss behavior. `ServerBossEvent` does not appear directly in registered entity bytecode because the custom bar is abstracted behind `LMBossInfoServer`.
