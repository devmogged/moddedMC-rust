# Create: New Age

Partial source-backed port of **Create: New Age `1.2.0+mc1.21.1`** (NeoForge). Original code is BSD-3-Clause (Antarctic Gardens). No original game assets are bundled.

The independent `src/energy_storage.rs` now ports `SimpleNetworkEnergyStorage`: 64-bit stored/capacity values, external per-call input/output limits, internal transfers, simulation, capacity clamping and transaction snapshot restoration. Its original transactional host hooks and final-commit callbacks are not yet connected. One test combines energy-handler acceptance with the network's shared edge conductivity, checking conservation of received FE. The Rust crate currently implements the generator coil's twelve magnet offsets around X, Y and Z shafts, its magnet-dependent stress and FE production, and the consume-once generated-energy buffer. `src/electrical_network.rs` also ports `NetworkPathManager` and `NetworkPathConductivityContext`: shortest-path BFS with configurable depth, edge budgets that reset each tick, no longer-path fallback when saturated, and the consumer distribution loop. Source: `GeneratorCoilBlockEntity`, `RelativeBlockPos`, `ElectricalNetwork` and the path manager classes in the public 1.21.1 source. The generator `tick()` was checked against the published 1.2.0 NeoForge jar. Conversion uses the original configurable `suToEnergy` value, supplied as a parameter.

Tests: `cargo test -p create-new-age`, `cargo clippy -p create-new-age --all-targets -- -D warnings`.

This is an `rlib` for source-comparison and standalone logic tests, **not yet a loadable `.mmc`**. The pure network caller supplies each receiver's acceptable capacity, while the original Java network asks the installed energy handler to insert each transfer, so per-call handler constraints and equal-length-path iteration order still need original-mod oracle tests. Full gameplay needs Create's inter-mod kinetic source/consumer service (`WS-4-01`) and registered electrical connectors, magnets, item/block content and persistence. An original Java-mod oracle must verify stress, network power delivery and restart before calling the mechanic ported.
