# Simple Storage Network

Local M1 preview of Simple Storage Network NeoForge 26.1.2-1.13.2. Includes the isolated Network Cable, its shaped recipe and its loot table. Uses a vanilla texture on an original model. Connections, waterlogging, block entity data, transfer, terminals and Java parity remain to be implemented or verified.

Build with `scripts/pack-mod.ps1 -Crate simple-storage-network`. Run `scripts/scenario.ps1 -Scenario tests/scenarios/simple-storage-network-cable.txt -Port 26200` with the engine and bot available. The scenario checks recipe unlock, not actual crafting.
