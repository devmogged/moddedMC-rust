# Attribution and license

This port adapts the MIT-licensed [Create More Recipes](https://github.com/iglee42/create-more-recipes) by iglee42, targeting its `1.2.1-fix1` NeoForge 1.21.1 release.

- Java behavior reference: source branch `1.21.1`, commit `79cc098`.
- Data reference: the actual `Create More Recipes-1.21.1-1.2.1-fix1.jar`, extracted locally into the ignored `cache/ws4/` directory.
- Code, crafting recipe, loot tables and item tags in this port: MIT.
- No textures, sounds, models, Minecraft JARs or downloaded mod binaries are committed. To see original assets with a stock client, supply a legal local copy of the original addon jar in `MODDEDMC_ASSET_JARS`.

The port is still incomplete. Only its cooler and adjacent data work today; the Create basin/mixer integrations and snow-golem capture require host interfaces that are not yet available.
