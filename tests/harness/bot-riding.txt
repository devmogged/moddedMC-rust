area 0 150 0 5 153 5
start
cmd fill 0 150 0 5 150 5 minecraft:stone
bot join alice

cmd summon minecraft:oak_boat 2.75 151 1.5
bot alice expect riding none
bot alice interact minecraft:oak_boat 2.75 151 1.5 main
bot alice expect riding minecraft:oak_boat
bot alice input sneak
bot alice expect riding none
bot alice input none
stop
