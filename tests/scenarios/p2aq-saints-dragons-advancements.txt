# Saint's Dragons advancements from 0.9.88. The server tracks the mod's datapack advancements:
# holding a Draconic Codex triggers the root's inventory_changed criterion, the mod awards its
# impossible criteria (clicking a dragon, taming one), and /advancement accepts their ids.
mods target\mods\saints-dragons-roosts\saints-dragons.mmc
start
expect Added \d+ datapack advancements to the advancement tree
botstart tester
wait 3
cmd op tester
cmd gamemode creative tester
cmd gamerule minecraft:spawn_mobs false
cmd tp tester 1025.5 100 1029.5
cmd forceload add 1025 1025
wait 3
cmd fill 1013 99 1013 1037 99 1037 minecraft:stone
cmd fill 1013 100 1013 1037 110 1037 minecraft:air
cmd item replace entity tester hotbar.4 with saintsdragons:draconic_codex
wait 1
cmd execute if entity @a[name=tester,advancements={saintsdragons:root=true}]
wait 0.5
expect Test passed
cmd saintsdragons spawn stegonaut 1025 100 1025
wait 2.5
cmd item replace entity tester weapon.offhand with minecraft:salmon
wait 0.5
bot use-entity ravager 1025.5 100 1025.5 off
wait 0.5
expect Stegonaut has been tamed!
cmd execute if entity @a[name=tester,advancements={saintsdragons:encounter_dragon=true,saintsdragons:tame_stegonaut=true}]
wait 0.5
expect Test passed
cmd execute if entity @a[name=tester,advancements={saintsdragons:why=true}]
wait 0.5
expect Test failed
cmd advancement grant tester only saintsdragons:why
wait 0.5
cmd execute if entity @a[name=tester,advancements={saintsdragons:why=true}]
wait 0.5
expect Test passed
reject (?i)panic|panicked|\[bot\] error
bot quit
stop
