# Saint's Dragons 0.9.88: three saddle carriers, five saddle-free owner mounts.
# Cindervane's second seat is covered by the policy test; the scenario uses one bot.
# Manual companion acceptance (requires a real companion client):
# For each of the eight dragons below, mount and move through idle, locomotion,
# flight/swim where applicable and mounted attacks. The rider must follow the
# animated passengerLocator, not the neutral server attachment. For Cindervane
# also check passengerBone1/2 with two riders; slash-grab has a separate scenario.
# Nulljaw hangs below its locator by 1.65 blocks. Ground dragons use a locator
# only when sampled within the last two ticks. Turn sharply, switch clips and
# dismount/remount; check that first-person camera and third-person rider track
# the seat, that two nearby dragons do not share anchors, and that a missing
# rig or locator falls back to the ordinary seat. The headless bot checks logical
# mounting/dismounting; it cannot observe these client render positions.
start
botstart tester
await 60 \[bot\] joined as tester
wait 10
cmd op tester
cmd gamerule minecraft:spawn_mobs false
cmd forceload add 1013 1013 1037 1037
cmd tp tester 1025.5 100 1028.5
wait 20
cmd fill 1013 99 1013 1037 99 1037 minecraft:stone
await 30 Successfully filled|No blocks were filled
cmd fill 1013 100 1013 1037 110 1037 minecraft:air
await 30 Successfully filled|No blocks were filled
cmd time set day

# Stegonaut
cmd gamemode creative tester
cmd tp tester 1025.5 100 1028.5
cmd saintsdragons spawn stegonaut 1025 100 1025
await 30 saintsdragons:stegonaut: spawned
cmd data merge entity @e[type=minecraft:ravager,nbt={data:{moddedmc:{mob:"saintsdragons:stegonaut"}}},limit=1] {NoAI:1b}
cmd tp @e[type=minecraft:ravager,nbt={data:{moddedmc:{mob:"saintsdragons:stegonaut"}}},limit=1] 1025.5 100 1025.5
cmd item replace entity tester weapon.offhand with saintsdragons:creative_dragon_tame_meal
wait 0.5
bot use-entity ravager 1025.5 100 1025.5 off
wait 0.5
expect Dragon tamed\.
cmd item replace entity tester weapon.offhand with minecraft:air
cmd item replace entity tester weapon.mainhand with minecraft:air
cmd gamemode survival tester
wait 0.5
bot use-entity ravager 1025.5 100 1025.5 main
wait 0.5

bot expect riding none
wait 0.5
expect \[bot\] expect riding ok none

wait 0.5

wait 0.5

wait 0.5
expect \[bot\] expect inventory ok slot 36

wait 0.75

expect \[bot\] expect riding ok ravager

wait 1
bot expect riding none
wait 0.5
expect \[bot\] expect riding ok none
bot input none
